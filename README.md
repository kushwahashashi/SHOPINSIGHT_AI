
# SHOPINSIGHT AI

### E-commerce Customer & Sales Intelligence Dashboard

SHOPINSIGHT AI is a Python-based data analytics project that transforms e-commerce data into meaningful business insights through interactive dashboards and visualizations.

## Project Overview

This project analyzes customer behavior, sales performance, order delivery, product categories, reviews, and seller performance using real-world e-commerce datasets.

The goal is to help businesses understand their customers, monitor sales, and make data-driven decisions.

## Key Features

- E-commerce sales and revenue analysis
- Customer segmentation based on purchasing behavior
- Repeat customer and retention analysis
- Order status and delivery performance analysis
- Product category performance insights
- Customer review and satisfaction analysis
- Seller revenue contribution analysis
- Interactive dashboard visualizations

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- VS Code
- Git & GitHub

## Dataset

This project uses the Brazilian E-Commerce Public Dataset by Olist.

The dataset contains information about customers, orders, payments, products, sellers, reviews, and geolocation.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/kushwahashashi/SHOPINSIGHT_AI.git
cd SHOPINSIGHT_AI
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the dashboard

```bash
streamlit run dashboard.py
```
